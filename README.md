# Напоминалка для macOS

Настольное приложение-напоминалка на Python для macOS. Напоминания хранятся в базе SQLite3, а в назначенное время появляются в виде системного уведомления и окна поверх всех окон, даже если программа свёрнута.

## Возможности

- Добавление напоминания: заголовок, описание, дата и время срабатывания
- Удаление напоминания
- Отметка «Готово» или «Отменено»
- Автоматический перевод в статус «Просрочено»
- Просмотр списка с фильтром по статусу

Статусы напоминаний:

| Статус | Когда устанавливается |
|---|---|
| Ожидает | Сразу после создания и после «Отложить» |
| Готово | Пользователь нажал «Готово» |
| Отменено | Пользователь нажал «Отменить» |
| Просрочено | Через 5 минут после срабатывания, если напоминание всё ещё не отмечено |

## Как это работает

1. Раз в 5 секунд программа проверяет базу.
2. Когда наступает время напоминания:
   - приходит системное уведомление macOS со звуком;
   - открывается окно поверх всех окон с кнопками **Готово**, **Отложить на 10 мин**, **Отменить** и **Закрыть**.
3. Если за 5 минут после срабатывания напоминание не отмечено как «Готово» или «Отменено», его статус меняется на «Просрочено».
4. Если в момент срабатывания программа была закрыта, уведомление появится при следующем запуске.

Красная кнопка закрытия только сворачивает окно в Dock, уведомления при этом продолжают приходить. Клик по иконке в Dock разворачивает окно. Полный выход — **⌘Q**.

## Требования

- macOS (рассчитано на macOS 26 Tahoe)
- Python 3.10 или новее с tkinter. Python с python.org уже включает tkinter.
- Необязательно: `pyobjc-framework-Cocoa`. С ним macOS не «усыпляет» программу в фоне (App Nap), и уведомления не опаздывают, когда окно свёрнуто.

## Установка и запуск

```bash
cd путь/к/папке/notification
pip3 install pyobjc-framework-Cocoa   # необязательно, но рекомендуется
python3 main.py
```

При первом запуске рядом с программой создаётся файл базы `reminders.db`, а в нём нужные таблицы. При следующих запусках программа проверяет таблицы и создаёт их, только если они отсутствуют.

### Разрешение на уведомления

Системные уведомления отправляются через `osascript`, поэтому macOS показывает их от имени **Редактора скриптов** (Script Editor). Если уведомления не приходят, откройте **Системные настройки → Уведомления → Редактор скриптов** и разрешите уведомления. Окно поверх всех окон появляется и без этого разрешения.

## Использование

- **Добавить:** кнопка «＋ Добавить». Введите заголовок и описание, укажите дату (`ДД.ММ.ГГГГ`) и время (`ЧЧ:ММ`) или нажмите одну из быстрых кнопок: «+15 мин», «+1 час», «+1 день». Время должно быть в будущем.
- **Отметить:** выберите напоминание в списке и нажмите «✓ Готово» или «✕ Отменить».
- **Удалить:** кнопка «Удалить» или клавиши Delete / Backspace (программа попросит подтверждение).
- **Фильтр:** выпадающий список «Фильтр» вверху окна: все напоминания или только с выбранным статусом.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа: открывает базу и запускает окно |
| `db.py` | Работа с SQLite3: схема таблиц, добавление, удаление, смена статусов, выборки |
| `notifier.py` | Системные уведомления, всплывающее окно и планировщик проверок |
| `gui.py` | Главное окно на tkinter и окно добавления напоминания |
| `reminders.db` | База данных (создаётся автоматически) |

## Настройки

Параметры задаются константами в начале `notifier.py`:

| Константа | По умолчанию | Что задаёт |
|---|---|---|
| `CHECK_INTERVAL_MS` | 5000 мс | Как часто проверять базу |
| `OVERDUE_GRACE` | 5 минут | Через сколько после срабатывания напоминание становится «Просрочено» |
| `SNOOZE_DELTA` | 10 минут | На сколько откладывает кнопка «Отложить» |
